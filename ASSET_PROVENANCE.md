# Asset provenance

The Godot game uses original project art, procedural UI and engine/runtime output.

## Current assets

- `game/assets/icon.svg`: project-authored geometric bank icon. It uses no
  Federal Reserve seal, logo or photograph and does not depict an official site.
- `game/art/build_city.py`: project-authored deterministic Blender miniature,
  with procedural geometry and materials. Seed 41 controls building variation.
- `game/art/policy_city.blend`: editable source generated by that script.
- `game/assets/policy_city.glb`: generated city loaded by Godot. It illustrates
  an economy; it is not a calibrated regional model or real Federal Reserve site.
- Godot panels, charts and controls: authored in `game/play/`. System fonts are
  requested at runtime and are not redistributed as project asset files.

The original Swift UI assets are retired to Git history. No external textures,
photographs, audio packs or copied game assets are bundled. The current game
has no bundled audio files.

For changes, retain the authoring source and generated asset together, record
provenance here, inspect the actual game rendering and preserve clean-room rules.
Godot's built-in resources and third-party components retain their own notices;
see `THIRD_PARTY_NOTICES.md` and the in-game Credits panel.
