# Asset provenance

The Godot game uses original project art, procedural UI and engine/runtime output.

## Current assets

- `game/assets/icon.svg`: project-authored geometric bank icon. It uses no
  Federal Reserve seal, logo or photograph and does not depict an official site.
- `game/art/build_city.py`: project-authored deterministic Blender miniature,
  with procedural geometry and materials. Seed 41 controls window lighting and
  canal glints. The refined city derives its visual direction from the retained
  GPT-image reference below, not from copied building meshes or textures.
- `game/art/policy_city.blend`: editable source generated by that script.
- `game/assets/policy_city.glb`: generated city loaded by Godot. It illustrates
  an economy; it is not a calibrated regional model or real Federal Reserve site.
- Godot panels, charts and controls: authored in `game/play/`. System fonts are
  requested at runtime and are not redistributed as project asset files.

## Soundtrack

JRB-1 is credited to Jared Bland personally, at his direction, and was generated
with Suno. Suno lists the selected song at
<https://suno.com/song/8436d628-5c56-4f0e-953c-da58786e26b9>, shared at
<https://suno.com/s/lWA6lJD3HljjnaqV>. Its public page identifies Jay
(@thelitinvestor); ownership attribution follows Jared's direct declaration,
not a verification of account tier, provider terms or copyright protectability.
The qualified project license in `LICENSE` applies to rights held by Jared;
third-party rights remain separate.

`art/audio/JRB-1.m4a` is the original file downloaded through Suno's signed-in
M4A download on 19 October 2026, retained byte-for-byte. It contains Opus audio
in an MP4 container and replaces the earlier video-derived AAC remux.
`game/assets/audio/jrb-1.wav` is its PCM16 stereo 48 kHz decode, without trimming,
normalization or structural edits. Godot imports it uncompressed and loops the
complete sample. The source and conversion hashes, bytes, duration and origin
are recorded in `art/audio/manifest.json`. Both files passed full decoding;
listening quality requires separate acceptance. The runtime plays the bundled
file locally, with no Suno client, credentials, live generation or network calls.

## Refined city reference

`art/references/policy-city-direction-20261002.png` was generated with the built-in
GPT image model on 2026-10-02 and inspected before native asset editing.
Its SHA256 is `da9041ec63f2ec1e8bc115204882cfb3d2ca03348a172c7bb1d44d5b02102a30`.
The editable Blender city uses its limestone civic hall, teal setback towers,
ivory neighborhoods, restrained brass trim and canal frontage as a design
reference. The generator builds original native meshes and twelve procedural
materials; no reference pixels, textures or model inference run during gameplay.

Small-panel simplifications include abstract pediment relief rather than carved
figures, opaque teal glazing, sparse static water glints, simple planted canopies
and three low-poly arched crossings. Semantic/material joins bound draw surfaces
while leaving mesh geometry editable in Blender. The reference is a visual
target, not evidence that native output matches its detail or lighting.
Current-source game pixels and usability require separate validation under
`docs/AGENTIC_GUI_VALIDATION.md`.

The original Swift UI assets are retired to Git history. No external textures,
photographs, audio packs or copied assets from another game are bundled.

For changes, retain the authoring source and generated asset together, record
provenance here, inspect the actual game rendering and preserve clean-room rules.
Godot's built-in resources and third-party components retain their own notices;
see `THIRD_PARTY_NOTICES.md` and the in-game Credits panel.
