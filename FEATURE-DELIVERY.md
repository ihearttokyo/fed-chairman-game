# Major-feature delivery

Deliver actual behavior and assets, a matching playable release, source-linked
private walkthroughs, and accurate README/public download information.

Define intended-use acceptance before implementation. Use independent adversarial
assessment; keep private ratings from the author and supply concrete fixes only.
Freeze accepted source/artifact identities. Do not hill-climb accepted work again
without a material regression or changed requirement. Nonblocking polish does not
hold an otherwise qualified preview indefinitely.

Artwork must be reviewed at its intended runtime size, with true provenance,
originals and editable source retained. Preserve full keyboard access, responsive
layout, clear units, concise feedback and deeper explanations on demand.

Inspect all human and bot GitHub review surfaces before exact-SHA merges. Reuse
unchanged validation, run affected checks, preserve repository protections and
avoid redundant CI. Qualify the actual distributed artifact; merged is not
installed or published. Keep one verified rollback and preserve player saves.
